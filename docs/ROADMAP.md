# Build plan and next milestones

## Phase 0: inspectable baseline (delivered)

Local resources and signaling, bounded self-maintenance and receptor adaptation, inherited controller mutations, reproduction/death, explicit energy accounting, seeded replay, persistent single-container deployment, browser interventions/inspector, headless ablations, and automated tests.

Acceptance is mechanical: a barrier blocks diffusion, a knockout suppresses the corresponding inputs, mutations are heritable and bounded, saved state resumes identically, resource transactions balance, and the application restarts from a checkpoint. Visual complexity alone is not acceptance.

## Phase 1: better evolutionary evidence

Add streaming histories, complete lineage birth/death events, parent reproductive output, trait-distribution panels, multiple replicates, confidence intervals, and statistically specified intervention experiments. Separate sensing, secretion, and their costs. Add predefined input-schedule files and a lossless external intervention log.

Gate: demonstrate repeatable inherited changes under a prespecified environmental challenge, with neutral and cost-matched controls. Distinguish drift, artificial initialization bias, and genuine selection. No claim that all increased variation is adaptation.

## Phase 2: evolve communication architecture

Introduce variable receptor/channel tables, gene duplication/deletion, sparse regulatory graphs, and evolvable signal matching. Keep maximum sizes, costs, schema migration, seeded mutation operators, and invalid-genome handling explicit. Genomes remain bounded data in a sandbox; they do not become host scripts or self-deploying programs.

Gate: communication conventions must be discovered rather than encoded in channel names or a target phenotype. Measure the information and resource value of each new signaling component.

## Phase 3: development and collective maintenance

Add cell attachment/adhesion, local mechanical constraints, differentiation, energy/matter transport, and controlled multicellular reproduction experiments. Use connected components as observational candidates, not definitions of organism identity. Add trained neural cellular automata as a separate experimental controller family, with published training objectives and held-out damage tests.

Gate: show stable coordination and repeatable collective reproduction/regeneration beyond passive adjacency. A built-in "repair shape" instruction does not count as evolved development. Trained NCA and ecological evolution should remain clearly labeled distinct mechanisms.

## Phase 4: larger ecologies and performance

Profile the baseline, then introduce workers/GPU field updates, ecological resource transformations, and richer environmental modification. Define conservation rules, precision guarantees, execution ordering, and CPU/GPU equivalence tests before trusting results. Preserve a slow, transparent reference implementation.

Gate: model-equivalence tests and meaningful throughput gains on specified hardware. Avoid calling numerical artifacts new species.

## Phase 5: richer cognition experiments

Add evolving internal memory, recurrent controllers with variable topology, local plasticity rules, sensorimotor tasks, and predictive-state probes. Evaluate behavior against matched simpler controllers. Separate learning, inference, memory, metacognition, and subjective consciousness.

Gate: functional capacities have independent tests. No score or visual pattern is treated as proof of consciousness. Long-lived or increasingly complex runs are not automatically evidence of unbounded open-ended evolution.

## Non-goals for this release

Molecular fidelity, human brain emulation, free-form host code mutation, Internet-connected autonomous agents, external tool use, cryptocurrencies, cloud accounts, distributed deployment, or claims of perpetual self-sufficiency. The world needs compute, a supplied resource process, and explicit model assumptions.
